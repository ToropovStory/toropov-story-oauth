Конфиденциальность

Toropov Story использует OAuth Google для доступа к сведениям о собственном канале владельца, видео и аналитическим отчётам, включая доступные финансовые отчёты. Приложение не получает пароль Google.

Данные используются для анализа канала, подготовки предложений и выполнения согласованных изменений. Реквизиты OAuth и токены хранятся на Mac владельца в файлах с ограниченными правами доступа. Они не размещаются в публичном репозитории и на этом сайте.

При работе с помощником Codex выбранные данные канала передаются в OpenAI для обработки. Их обработка в сервисе регулируется условиями OpenAI и настройками аккаунта пользователя. Публичный сайт не запрашивает вход в Google и не собирает данные канала.

Данные не продаются владельцем приложения и не используются приложением для рекламного таргетинга. Использование информации, полученной через Google API, регулируется Google API Services User Data Policy, включая требования Limited Use.

Токены и выгрузки сохраняются для работы с каналом, пока владелец не удалит их. Доступ можно отозвать через подключения аккаунта Google. Отзыв доступа не удаляет ранее сохранённые локальные файлы и чаты: ими владелец управляет отдельно.

Вопросы об этом приложении можно направить через репозиторий проекта. Не публикуйте там пароли, токены, личные данные или закрытую аналитику.
