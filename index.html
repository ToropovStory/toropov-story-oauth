Toropov Story

Личное приложение Андрея для работы с собственным YouTube-каналом Toropov Story.

Приложение получает сведения о видео и аналитику через официальные API Google. Изменения названий, описаний, тегов и других данных выполняются только после отдельного согласования с владельцем канала.

Инструмент предназначен для личного использования, а не для подключения каналов других пользователей.
